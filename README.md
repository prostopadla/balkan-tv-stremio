# Balkan TV for Stremio

Static Stremio addon with free TV channels from Serbia, Croatia, Bosnia and Herzegovina, Montenegro, Slovenia and North Macedonia (from the open iptv-org catalog, checked for availability).

Install page: https://avinkoapps.github.io/balkan-tv-stremio/

Manifest: https://avinkoapps.github.io/balkan-tv-stremio/manifest.json
